# Ryedough's Simple OBJ Loader
an incomplete, dead simple obj loader in c  
written as a requirement to implement [OpenGL in c](https://github.com/ryedough/gl_ballz)  
it also use my stupidly simple unsafe [dynamic array](https://github.com/ryedough/c_dynamic_array)  
to use, just static link the libobj_loader.a and include obj_loader.h in your project
